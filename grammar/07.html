G6：て形

功能

て形是動詞的「連接形」——把多個動作串在一起，或作為其他句型的基礎（G7 ている、G9 てください 等）。

變化規則

て形是從原形推的，看語尾分五組。第 6 章那九個語尾在這裡剛好三個併一組，所以只要記五條規則。

原形語尾て形例字羅馬拼音中文
う・つ・るってかう → かってkau → katte買
まつ → まってmatsu → matte等
のる → のってnoru → notte搭乘
ぬ・ぶ・むんでしぬ → しんでshinu → shinde死
あそぶ → あそんでasobu → asonde玩
のむ → のんでnomu → nonde喝
くいてかく → かいてkaku → kaite寫
きく → きいてkiku → kiite聽、問
ぐいでいそぐ → いそいでisogu → isoide趕
ぬぐ → ぬいでnugu → nuide脫
すしてはなす → はなしてhanasu → hanashite說
かす → かしてkasu → kashite借出

上面五組只管う動詞。另外三類各自更簡單：

類型做法例字羅馬拼音中文
る動詞去る＋てたべる → たべてtaberu → tabete吃
みる → みてmiru → mite看
する動詞する → してべんきょうする → べんきょうしてbenkyou suru → benkyou shite讀書
くる整個換掉くる → きてkuru → kite來

⚠️ 唯一的不規則：いく（行く，去）→ いって（itte），不是いいて。它語尾是く卻走「って」那一組，是て形裡最常考的例外，背這一個就夠。

助記口訣（日本小學生也用這套）：うつる → って、ぬぶむ → んで、く → いて、ぐ → いで、す → して，然後補一句「行く例外」。

從ます形推也可以

如果妳習慣從第 6 章的ます形出發，把ます拿掉之後看最後一個音，對應關係是一樣的：

ます形語尾て形例
い・ち・りってかいます → かって
に・び・みんでのみます → のんで
きいてかきます → かいて
ぎいでいそぎます → いそいで
ししてはなします → はなして

（注意這裡的「き」是かきます、ききます那個き。くる 的ます形也是きます，但它走的是最後一類，きて。）

從 conversation.md 認識的て形

句子て形原形
ちょっとまってまってまちます（待ちます）
がんばって！がんばってがんばります（頑張ります）

て形單獨用在口語裡，帶有「繼續做」或「輕輕請求」的語感：

  • まって＝等一下（比 まってください 更口語）
  • がんばって＝加油（鼓勵用，不是命令）

這一課的單字：常用寒暄

今天的九句寒暄，重點不是硬背，是看出它們兩兩成對——日本人的日常寒暄幾乎都是一問一答。九句裡有五句妳已經學過，今天把新舊排在一起，配對關係才顯得出來。

第一組：出門與送別

いってきます ittekimasu 我出門了

拆開就是「行って来ます」＝行く（去）的て形＋来ます（回來）。字面是「我去了會回來」——日本人出門不講「我走了」，講「我去去就回」，這個觀念差異比讀音更值得記。行 音読み こう，台語「行」hîng；来 音読み らい，台語「來」lâi，l 對 r 是老規矩。

例句：いってきます。（我出門了。）

いってらっしゃい itterasshai 路上小心

是「行っていらっしゃい」縮短來的。いらっしゃる是行く／来る／いる三個動詞共用的尊敬語，所以整句字面是「請您去了再回來」。中間那個っ就是縮讀留下的停頓（發音規則六，台語入聲的音感）。

例句：いってらっしゃい。（路上小心。）

這兩句是固定一組：出門的人說いってきます，留在家的人答いってらっしゃい，順序不會反。

第二組：回家

ただいま（已學，我回來了）→ おかえりなさい okaerinasai 你回來了

お帰りなさい＝帰る（かえる，回家）的ます形去掉ます，再加なさい。なさい是丁寧的命令形「請〜」，和おやすみなさい是同一個結構。字面「請回來」，實際功能是迎接。熟人之間可以省成おかえり。帰 音読み き（本字「歸」），台語「歸」kui → き，母音對得漂亮。

例句：おかえりなさい。ごはんですよ。（你回來啦，吃飯囉。）

第三組：吃飯

いただきます（已學）→ ごちそうさまでした gochisousamadeshita 謝謝招待

いただきます的「頂く」原意是「舉到頭頂」，收下食物時把它高舉過頭，所以是謙讓語。頂 音読み ちょう，台語「頂」tíng。

ごちそうさまでした漢字寫「御馳走様でした」——馳走（ちそう）就是「奔走」。古時候要招待客人，主人得騎馬四處張羅食材，所以這句字面是「多謝您為我奔走」。馳 台語 tî → ち，走 台語 tsáu → そう。飯後才說，用過去式でした是因為那頓飯已經結束了。

例句：ごちそうさまでした。おいしかったです。（謝謝招待，很好吃。）

第四組：道別三階

  • おやすみなさい（已學，お休みなさい）睡前用。休 音読み きゅう，台語「休」hiu——h 對 k 是台語日語的一整組對應（花 hoe／か、海 hái／かい）。
  • さようなら（已學）字源是「左様ならば」＝「若是那樣的話」。話說一半就走，所以帶著「以後不一定再見」的重量，跟同事下班道別別用它。
  • じゃあね（已學）＝では＋ね，では口語化成じゃあ，最輕鬆。

またね matane 待會見

また＝「又、再」（漢字寫「又」），ね是語尾。字面「又見囉」，比じゃあね多一層「還會再見」的保證，是最安全好用的一句。またあした（明天見）、またらいしゅう（下週見）都是同一個模子套出來的。

例句：じゃあ、またね。（那，待會見。）

完整表：一天的寒暄

把新學的和已學的排進一天的時間軸，成對關係一眼就看得到。粗體是今天新學的。

場景說的人回的人
早上見面おはようございます ohayou gozaimasuおはようございます
白天見面こんにちは konnichiwaこんにちは
晚上見面こんばんは konbanwaこんばんは

道別則是一條「親疏軸」，從最輕鬆到最重：

說法羅馬拼音語感什麼時候用
じゃあねjaane最輕鬆朋友，馬上還會見
またねmatane輕鬆但有保證最安全好用，帶「還會再見」
またあしたmata ashita輕鬆＋指定明天還會見到的人
では、またdewa mata稍正式同事、客戶
しつれいしますshitsurei shimasu正式離開別人的辦公室、先走一步
さようならsayounara最重長期分別；同事下班別用

おそまつさまでした（粗茶淡飯，招待不周）是主人的固定回應，聽得懂就好，自己下廚招待人時才會用到。

一句話收尾：寒暄語幾乎都是「動詞＋敬語外殼」的化石，拆開來就有意思——行って来ます、お帰りなさい、御馳走様。
