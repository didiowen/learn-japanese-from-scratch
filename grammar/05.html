G4：あります／います

功能

表示「存在」——東西在哪裡、有沒有某東西。

動詞用於意思
あります無生命的物（物品、店、事件）有／在
います有生命的（人、動物）有／在

⚠️ 植物用 あります，機器人用 あります，但機器人如果像人就用 います（語感問題）。

句型一：X が あります／います（有 X）

日文中文
ねこが います。有貓。
コンビニが あります。有便利商店。
じかんが ありません。沒有時間。

句型二：X は Y に あります／います（X 在 Y）

X  は  場所  に  あります／います
主語     地點  助詞
日文中文
ねこはテーブルの上にいます。貓在桌子上。
コンビニはえきの前にあります。便利商店在車站前。
わたしはうちにいます。我在家。

前兩句的 Y 都是「名詞＋の＋位置詞」：テーブルのうえ、えきのまえ。 位置詞在日文是名詞不是介系詞，所以要用 の 接上去，不能像英文的 on／in 那樣 直接擺在前面。第三句的 うち 本身就是地點，不必再加位置詞。

位置名詞完整的一組（うえ／した／まえ／うしろ／となり／よこ／なか／そと／
あいだ／ちかく／かど…）連同成對關係與台語對照，列在本課後面的單字段落，
這裡不重複。

あります 的特殊用法：事件

日文中文
あしたテストがあります。明天有考試。
らいしゅうパーティーがあります。下週有派對。

這一課的單字：場所設施 A

今天八個字分兩半：前五個是家裡的空間（台所・風呂・庭・玄関・窓），後三個是外面的設施（動物園・博物館・郵便局）。

分界不只是意思，讀法也分兩派。家裡的空間多半走訓読み（にわ、まど、ところ），是日本人本來就有的和語；外面的設施全是音読み三連發（どうぶつえん、はくぶつかん、ゆうびんきょく），從漢語整套借進來的。這正是批次6 毎朝あさ／毎日にち 那條音訓分流，換一個題材再演一次。

而且後三個字裡藏著一條台語規律的完整示範——入聲韻尾。昨天的 末 bua̍t→まつ 只是其中一格，今天會把整張表補齊。

一、家裡的五個地方

台所 だいどころ daidokoro 廚房

拆成 台 ＋ 所。

台 妳已經會兩個詞：台風 たいふう、台湾 たいわん，都念清音 たい（台語「台」tâi ✅）。台所 這裡濁化成 だい，所以「台」有 たい／だい 兩個音読み。

所 也有兩讀：音読み しょ（台語「所」sóo ✅——場所 ばしょ、住所 じゅうしょ）、訓読み ところ。台所走訓読み那條，而且接在前字後面時清音變濁音，ところ → どころ。這叫連濁，妳學過的 花火 はな＋ひ→はなび、手提げ袋 ふくろ→ぶくろ 是同一個機制。

語源很實在：平安時代放餐具檯的房間叫「台盤所 だいばんどころ」，縮短就成了台所。

例句：ははは だいどころに います。（媽媽在廚房。）

風呂 ふろ furo 浴室、浴缸

這個字要特別提醒：風呂的漢字是借字（当て字），不能拆開算音読み。風不念 ふ、呂 也不是常見的 ろ，整個詞當一個單位記就對了。

不過「風」這個字本身值得整理，到今天它有三張臉：

  • かぜ（訓読み）——風、風邪 かぜ（感冒）
  • ふう（音読み）——台風 たいふう。台語「風」hong ✅，h→ふ 走的是發音規則第二條，は行古代念 p
  • ふ（風呂的借字）——不講道理，背下來

日常講一定加お：おふろ。動詞搭配是「おふろに入る」（批次11 會學 入る はいる）。日本的おふろ是泡澡的浴缸，跟シャワー（淋浴）分得很清楚，不是同一件事。

例句：まいばん おふろに はいります。（每晚泡澡。まいばん 是批次6 的字。）

庭 にわ niwa 庭院

訓読み にわ、音読み てい。台語「庭」文言音 tîng ✅ 對得上 てい——庭園 ていえん、家庭 かてい。

分流規則和昨天一樣：單獨用一定念訓読み にわ，進了漢語複合詞才變 てい。にわ 是和語，音上跟台語無關，改用詞例記：中庭 なかにわ、庭師 にわし（園丁）。

例句：にわに ねこが います。（庭院裡有貓。）

玄関 げんかん genkan 玄關

中文的「玄關」其實是從日文借回去的。原本是禪宗用語，「玄妙な関門」——進入深奧世界的那道關卡，後來借去指房子的入口。

玄 げん：台語「玄」hiân ✅。h→が行 看起來跳，但這是規律的，kanji.md 收的 学 ha̍k→がく 就是同一條。詞例：玄米 げんまい。

関 かん：台語「関（關）」kuan ✅，子音母音都對。関西 かんさい、税関 ぜいかん。

今天有個同音陷阱要先講：関 かん（關卡）和 館 かん（建築）同音不同字，等一下博物館的「館」就是後者。関是通過的門、館是進去的房子。

用法提醒：玄関是進門脫鞋的那一小塊，不是走廊。くつは げんかんに あります。（鞋子在玄關。）

窓 まど mado 窗戶

訓読み まど、音読み そう。台語「窗」文言音 tshong ✅ → そう（ts→s），詞例 車窓 しゃそう、同窓会 どうそうかい（同窗會）。

まど 這個和語有個好用的記憶鉤（語源說法之一）：間（ま）＋戸（と）＝ 牆與牆之間的門 → まど。另有「目戸」的說法，但ま＋ど比較好記。

形近字提示：窓、空 そら、穴 あな 都是穴字頭，上半部那個「宀＋八」是同一個部件，指有開口的地方。

例句：へやに まどが ふたつ あります。（房間有兩扇窗。ふたつ 是批次4 的和語數詞。）

二、三個設施：入聲字尾三連發

這三個詞全部走音読み，而且每個都踩到台語的入聲韻尾。

動物園 どうぶつえん doubutsuen 動物園

  • 動 どう——台語「動」tōng ✅
  • 物 ぶつ——台語「物」bu̍t ✅，入聲 -t 收尾 → つ。這就是昨天 末 bua̍t→まつ、月 gua̍t→げつ 的同一條
  • 園 えん——台語「園」文言音 uân ✅

順便把「物」整理起來，它有三讀：もの（訓読み——食べ物、建物）、ぶつ（音読み——動物、博物館）、もつ（荷物 にもつ）。

例句：にちようびに どうぶつえんへ いきます。（星期天要去動物園。）

博物館 はくぶつかん hakubutsukan 博物館

  • 博 はく——台語「博」phok ✅，入聲 -k 收尾 → く；p→h 又是は行古音那條（同 百 pik→ひゃく）
  • 物 ぶつ——和動物園共用同一個字，讀法也一樣
  • 館 かん——台語「館」kuán ✅。旅館 りょかん、大使館 たいしかん

一個詞裡同時吃到 -k→く 和 -t→つ 兩種入聲，是很划算的一個字。

例句：あした はくぶつかんへ いきます。（明天要去博物館。）

郵便局 ゆうびんきょく yuubinkyoku 郵局

  • 郵 ゆう——台語「郵」iû ✅
  • 便 びん——台語「便」piān ✅（p→b 濁化）。這個字兩讀：びん（郵便、宅急便 たっきゅうびん、飛機的「便」＝班次）／べん（便利 べんり、不便 ふべん）
  • 局 きょく——台語「局」kio̍k ✅，又是入聲 -k→く

妳早就會的 薬局 やっきょく 剛好可以回頭解釋：薬 やく ＋ 局 きょく，やく 的く 撞上か行開頭，促音化成 やっきょく。這正是批次4 學的「いち＋か行→いっ」那條規則——它不是數字專用，是日語複合詞的通則。

例句：ゆうびんきょくは がっこうの となりに あります。（郵局在學校隔壁。）

三、台語入聲韻尾對照表

今天三個設施把這張表補得差不多了，整理起來以後可以直接推：

台語入聲收尾日文變成今天的字以前學過的
-kく博 phok → はく、局 kio̍k → きょく学 ha̍k → がく、六 lio̍k → ろく
-tつ物 bu̍t → ぶつ末 bua̍t → まつ、月 gua̍t → げつ
-pふ → う（長音）—十 si̍p → じゅう、合 ha̍p → ごう

例外要記一個：冊 tshik 是 -k 收尾，日文卻念 さつ（一冊 いっさつ）。kanji.md 已經註明，遇到就當特例。

另有一批 -t 字走ち不走つ，那是更早一層的呉音：一 it→いち、七 tshit→しち、八 pat→はち、日 ji̍t→にち。同一個字兩層都留著的也有——日 にち（呉音）／じつ（漢音，本日 ほんじつ）。看到 -t 收尾，答案在 つ 和 ち 之間二選一。

規律本身很好用：看到台語是短促收尾的字，日文八成是兩拍的音読み，第二拍就在く／つ／う 三個裡面挑。

規律：園是有邊界的一塊地（動物園、公園、遊園地），館是一棟給人進去的大建築（博物館、映画館、水族館），局是處理事務的窗口機關（郵便局、薬局）——所以電影不是「映画園」，郵件也不是「郵便館」。

郵便局的招牌上是〒這個記號，來自舊「逓信省」的テ。看到〒就是郵局，不必認漢字。

這一課的單字：場所設施 B（含交通）

今天十個字分三堆：建物與行政區（銀行・工場・市・村）、位置關係詞（外・間・近く・角）、交通（バス停・飛行機）。

昨天把台語的入聲韻尾補成一張表：-k→く、-t→つ、-p→う。今天這批字剛好全是另外半邊——鼻音韻尾。銀 gîn、間 kan、村 tshun 是 -n；工 kang、行 hâng、停 thîng 是 -ng。兩邊合起來，台語一個字的收尾就能推出日文音読み的第二拍長什麼樣，那張表今天會補完。

另外今天有個小巧合可以利用：「行」這個字會出現兩次——銀行 ぎんこう、飛行機 ひこうき，同一個音読み。

一、兩棟建築：銀行與工場

銀行 ぎんこう ginkou 銀行

這是全批最漂亮的台語對應，台語念 gîn-hâng，日文念 ぎんこう，一個一個對：

  • 銀 ぎん——台語「銀」gîn ✅，子音母音全中。台語講錢就是「銀」（開銀、還銀），日文的 銀 也同時是金屬和顏色：銀色 ぎんいろ、銀メダル
  • 行 こう——台語「行」hâng ✅（就是「銀行 gîn-hâng」「行口」那個 hâng）。h→か行 妳已經見過兩次：学 ha̍k→がく、玄 hiân→げん（批次7），今天是第三次

「行」是個多讀字，值得整理一次：

讀法類型詞例意思
こう音読み（漢音）銀行・飛行機・旅行走、運行
ぎょう音読み（呉音）一行 いちぎょう・行事 ぎょうじ行列、一行字
い（く）訓読み行く いく去
おこな（う）訓読み行う おこなう舉行、實施

妳早就會的 行きます いきます 是訓読み那條；今天兩個新字走的是音読み こう。

例句：ぎんこうは えきの ちかくに あります。（銀行在車站附近。ちかく 是今天的字。）

工場 こうじょう koujou 工廠

  • 工 こう——台語「工」kang ✅。這個韻尾很重要：台語的 -ng 收尾，日文變成長音。妳早就會的 空港 くうこう 的「港」káng 也是同一條，所以 工 和 港 在日文裡同音
  • 場 じょう——台語「場」文言音 tiông，t 系子音進日文變 ちょう／じょう 兩層。會場 かいじょう、駐車場 ちゅうしゃじょう、運動場 うんどうじょう

⚠️ 工場有兩個讀法，意思有大小之分：

  • こうじょう——大型工廠（有生產線那種）
  • こうば——小工坊、街邊的鐵工廠（場走訓読み ば）

初學先記 こうじょう 就好，看到 こうば 知道它是小的。順帶一提，妳已經會的 場所 ばしょ 也是「場」的訓読み ば。

例句：ちちは こうじょうで はたらいて います。（爸爸在工廠工作。ちち 是批次1。）

二、台語韻尾對照表（補完）

昨天做了入聲那一半，今天把鼻音這一半補上。台語一個字怎麼收尾，就決定日文音読み第二拍是什麼——這是整套音読み最省力的一條規律。

台語韻尾日文第二拍今天的字以前學過的
-k（入聲）く角 kak → かく博 phok → はく、局 kio̍k → きょく、学 ha̍k → がく
-t（入聲）つ（少數ち）—物 bu̍t → ぶつ、末 bua̍t → まつ、月 gua̍t → げつ
-p（入聲）う（古代ふ）—十 si̍p → じゅう、合 ha̍p → ごう
-m（鼻音）ん—三 sam → さん、南 lâm → なん、金 kim → きん
-n（鼻音）ん銀 gîn → ぎん、間 kan → かん、村 tshun → そん、近 kīn → きん玄 hiân → げん、関 kuan → かん、先 sian → せん、園 uân → えん
-ng（鼻音）長音 う／い工 kang → こう、行 hâng → こう、向 hiòng → こう、停 thîng → てい動 tōng → どう、東 tong → とう、港 káng → こう、庭 tîng → てい

-ng 那一列要再分一次，看的是前面的母音：

  • 母音是 a／o／u → 收 う：工 kang→こう、東 tong→とう、動 tōng→どう
  • 母音是 i／e → 收 い：庭 tîng→てい、停 thîng→てい、青 tshing→せい（文言音）

為什麼鼻音變長音而入聲變一個假名？因為日語沒有 -ng 這個韻尾，只好用拉長母音替代；-n／-m 則剛好有 ん 可以接。入聲的 -k／-t／-p 是硬子音，日語只能加一個母音把它變成完整音節（く／つ／ふ）。

規律反過來也能用：看到日文音読み是「〇う」，台語八成是 -ng 收尾；看到是「〇ん」，台語就是 -n 或 -m。

三、行政區劃：市與村

市 し shi 市、城市

音読み し——台語「市」tshī ✅，ts→s 這條妳看過了：窓 tshong→そう、村 tshun→そん。

「市」有兩個完全不同的用法，讀法也跟著分：

  • し（音読み，行政區）——台北市 タイペイし、都市 とし、市民 しみん、市役所 しやくしょ（市公所）
  • いち（訓読み，市集）——魚市場 うおいちば、朝市 あさいち

⚠️ 所以 市場 有兩讀，意思也不同：いちば＝實體的傳統市場（菜市仔），しじょう＝抽象的市場（股市、市場經濟）。這又是一次音訓分流，跟批次6 的 毎朝あさ／毎日にち、批次7 的 庭にわ／庭園ていえん 同一條規則——和語的具體東西走訓読み，漢語的抽象概念走音読み。

例句：わたしは たいなんしに すんで います。（我住在台南市。）

村 むら mura 村莊

訓読み むら、音読み そん（台語「村」tshun ✅，ts→s ＋ -n→ん）。

分流規則和 市 一模一樣：單獨講一個村子念 むら，進了漢語複合詞才念 そん——農村 のうそん、村長 そんちょう。

記憶鉤：日本姓氏裡「村」超級常見，而且都念 むら——村上春樹 むらかみはるき（妳筆記裡的《国境の南、太陽の西》就是他的書）、中村 なかむら、木村 きむら、村田 むらた。看到姓氏裡的村，直接念 むら。

例句：おじいさんは ちいさい むらに すんで います。（爺爺住在一個小村莊。）

完整表：地方自治體三級

日本的地方行政單位是一組固定的階梯，三個一起記才看得出音訓怎麼分。

漢字假名羅馬拼音意思音読み（複合詞用）狀態
市しshi市し（都市・市民）🆕
町まちmachi城鎮、街區ちょう（町長）🆕
村むらmura村莊そん（農村）🆕

有趣的地方：市只有音読み一種念法（し），町和村卻是單用訓読み、複合詞音読み。原因是「市」這個行政層級是明治以後照漢語詞造的，而 まち／むら 是日本本來就有的聚落。

再往上還有「都・道・府・県」——東京都、北海道、大阪府／京都府、其他 43 個県（けん），合稱都道府県 とどうふけん。今天先知道有這一層就好。

四、四個位置關係詞

這四個字文法上都是名詞，不是介系詞。日文表達位置的公式固定是：

Aの＋位置詞＋に／で ——ex. つくえの うえに ある（在桌子上）

外 そと soto 外面

訓読み そと、音読み がい——台語「外」guā ✅，g→が 完全對上，同 銀 gîn→ぎん。

「外」的三個訓読み分工要分清楚：

  • そと——空間的外面（そとで あそぶ＝在外面玩），和 なか（中）成對
  • ほか——「其他」（ほかの ひと＝別人）
  • はず（す／れる）——脫落、偏離（めがねを はずす＝把眼鏡拿下來）

音読み がい 的詞很好用：外国 がいこく、外国人 がいこくじん、海外 かいがい、以外 いがい。⚠️ 例外一個：外科 げか（外科）念 げ 不念 がい。

例句：そとは さむいです。（外面很冷。）

間 あいだ aida 之間

這個字讀法最多，一次列清楚：

讀法詞例意思
あいだAとBの間兩者之間的空間或時段
ま居間 いま（客廳）・間に合う まにあう（趕得上）空隙、間隔
かん時間 じかん・週間 しゅうかん・期間 きかん一段時間
げん人間 にんげん（人類）世間

音読み かん——台語「間」kan ✅（中間 tiong-kan 的 kan），-n→ん。妳批次5 學的 じかん 的第二個字就是它，今天終於對上號。

用法公式：AとBの あいだに＝在 A 和 B 之間。

例句：ぎんこうは えきと ゆうびんきょくの あいだに あります。（銀行在車站和郵局之間。ゆうびんきょく 是批次7。）

近く ちかく chikaku 附近

這個字要先看清楚它的長相：它是 い形容詞「近い ちかい」去掉い、加く 變出來的。

  • 近い ちかい（形容詞，近的）→ 近く ちかく（名詞／副詞，附近）
  • 同一條規則：多い おおい→多く、遠い とおい→遠く、早い はやい→早く

（近い 本身是批次18 的字，那天會正式教它的活用；今天只用它的く形。）

音読み きん——台語「近」kīn ✅。最近 さいきん、近所 きんじょ（鄰居、附近一帶）、付近 ふきん。

⚠️ 位置用法有兩種寫法，意思一樣：えきの ちかく（車站附近）＝ えきの ちかくに。而 ちかい 是形容詞，要說「えきに ちかい」（離車站近）。名詞用の、形容詞用に，別混。

例句：うちの ちかくに こうえんが あります。（我家附近有公園。うち 是批次7。）

角 かど kado 轉角

音読み かく——台語「角」kak ✅，入聲 -k→く，昨天那張表今天唯一的一格。三角 さんかく、角度 かくど。

訓読み有兩個，指的是完全不同的東西：

  • かど——稜角、街角（曲がり角 まがりかど＝轉彎處）
  • つの——動物頭上的角（しかの つの＝鹿角）

同一個漢字兩個訓読み，靠意思分：長在身上的是 つの，路口和桌角是 かど。

例句：つぎの かどを みぎに まがって ください。（下個路口請右轉。みぎ 是舊字。）

五、交通：バス停與飛行機

バス停 バスてい basutei 公車站

這是個混血詞：片假名的外來語 バス（bus）＋漢字 停。日文很常這樣拼，像 消しゴム けしゴム（橡皮擦）也是。

停 てい——台語「停」thîng ✅。th→て，-ng 前面是 i 所以收 い，正好是上面那條細則的例子，而且和批次7 的 庭 tîng→てい 同音。停車 ていしゃ、停電 ていでん、バス停留所 ていりゅうじょ（バス停就是它的簡稱）。

⚠️ 三個「站」不能混：駅 えき是火車／電車站，バス停是公車站牌，空港 くうこう是機場。日文不會把公車站叫 駅。

例句：バスていは あの かどに あります。（公車站在那個轉角。）

飛行機 ひこうき hikouki 飛機

三個字全部音読み，而且每個都對得上台語：

  • 飛 ひ——台語「飛」hui ✅，h→は行 是發音規則第二條（は行古代念 p）
  • 行 こう——今天第二次出現，和 銀行 的行同一個音
  • 機 き——台語「機」ki ✅。機会 きかい、洗濯機 せんたくき（洗衣機，批次25 會教）

字面拆開就是「飛著行走的機器」，比中文的「飛機」還完整。

⚠️ 日中同形異義提醒：日文的 汽車 きしゃ 是火車（蒸汽車），不是中文的汽車；中文的汽車在日文叫 車 くるま 或 自動車 じどうしゃ。這個坑妳的 kanji.md 已經標過。

訓読み 飛ぶ とぶ＝飛（動詞）：とりが とんで います。（鳥在飛。）

例句：らいしゅう ひこうきで にほんへ いきます。（下週搭飛機去日本。らいしゅう 是批次5。）
